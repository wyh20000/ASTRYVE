## C. Electron 登录闭环与门禁

- [x] 主进程提供受信的登录状态、启动、取消、退出 IPC 白名单；启动登录时调用系统浏览器，并为该次请求独占随机端口的 `127.0.0.1` 回调监听。
- [x] 校验精确回调路径、端口、`state` 和时限，通过 HTTPS 用 PKCE verifier 换取会话；再次向服务端确认有效及用户 UUID 后才进入已登录态。完成/取消/退出时关闭监听，旧请求失效。
- [x] 使用受保护的本机存储保存会话；加密后端不可用时拒绝持久化，不把 token、授权码、平台凭据传给 Renderer、插件或日志。
- [x] 在主进程拦截业务 IPC，检查可信主框架来源与已验证会话；窗口遮挡或 React 状态不作为权限依据，覆盖发送消息、工作区、终端、设置、模型、插件、Skills 和审批等通道。
- [x] 登录确认前不初始化账号相关存储、插件、Skills 或后台任务，也不恢复旧任务；已有会话必须在线验证后才能重新开放服务。
- [x] 客户端锁定页显示产品标识、登录入口、浏览器等待、失败和重试；认证输入只在 Web 页，Three.js 背景支持减少动态效果和静态回退。
- [ ] 完成锁定页和 Web 表单的窄窗口、键盘操作及无视觉背景人工验收。

完成标准：无会话、错误回调、断网或服务端撤销时，Renderer 不能通过直接调用 preload API 读取或执行任何业务能力；正常回跳后仅主进程持有凭据。
