# M14 插件隔离界面设计

> 状态：代码与自动化基础已实现，保留为安全契约；真实窗口行为纳入 M14 人工验收。

## 范围

插件可在 `plugin.json` 声明 `"ui": "ui/index.html"`。该文件是至多 256KB 的自包含 UTF-8 HTML；包导入时只校验，不执行。用户在已安装插件详情页显式打开界面。禁用、更新、回滚或卸载插件时关闭其界面。

本轮不提供插件页面访问工作区、模型、凭据、工具或 MCP 的能力。插件页面无需自行从网络加载依赖；图片可使用内联 `data:` URL。后续若确需交互能力，必须逐项设计宿主动作与审批，不扩展通用 IPC。

## 隔离边界

- 主进程从已安装插件自身目录读取清单指定的 `ui/` HTML；拒绝绝对路径、越界路径、链接和超限文件。
- 每次打开使用独立 Electron `BrowserWindow` 和临时 session。启用 Chromium sandbox、context isolation、web security，关闭 Node integration。
- HTML 以 `data:` 文档加载，主进程先写入限制 CSP：仅允许文档内联脚本和样式及 `data:` 图片；禁止连接、外部脚本、frame、表单、对象和 worker。窗口打开新页、跳转、下载和权限请求均拒绝。
- 使用独立 preload，仅向插件页面暴露 `pluginHost.getInfo()` 与 `pluginHost.close()`。主进程按窗口 `webContents` 身份核对桥接调用，不接受页面自报插件 ID。
- 界面不共用主应用的 preload，也不能调用主应用的 `window.agent`。

## 验收

- 只有有效、已启用且声明 UI 的插件可打开窗口；包导入、发现和列表不会执行 HTML。
- 插件页面能显示，并能读取自身的非敏感名称、ID、版本和关闭窗口。
- 页面无法使用 Node/Electron、主应用 IPC、网络、文件路径、外链跳转、下载或浏览器权限。
- 插件禁用、更新、回滚和卸载时，已打开窗口关闭；独立窗口崩溃不影响主窗口。
