## 本轮代码与自动化

- 移除数据库接口及三种实现中可原地修改 `projectPath`/`kind` 的旧方法；新会话创建时要求项目路径与项目身份同时存在或同时不存在。已有旧记录的迁移路径不因该新建约束而删除。
- 前端不再仅凭空标题判定可复用，统一调用主进程；主进程检查类型、项目身份和可见消息，已有消息的无标题会话不复用。
- 定向测试：4 个测试文件、27 项通过；主进程和渲染进程类型检查通过；`npm run build` 通过。构建报告了已有的动态/静态导入混用提示，没有构建失败。
- 后续补测：MySQL 迁移失败关闭连接池，并以模拟旧会话测试重复迁移和类型归属；SQLite 旧消息及 JSON 导入在重启后仍保留；空白工作会话复用额外核对保存的项目路径。相关定向测试与主进程类型检查通过。模拟测试不等于旧 MySQL 实库验收。
- 顶部从「对话」切至「工作」改为先显示已有项目及完整路径供用户选择，也可选择其他项目或取消；不再自动进入最近项目。无匹配授权时，侧栏新建工作会话也不再静默改选另一项目。前端交互自动化覆盖选择、取消与键盘关闭；仍待真实桌面验收。
- `Ctrl+N` 和侧栏新建共用当前会话归属规则：工作会话只在匹配的已授权项目下新建，失效时要求重选，普通对话仍新建无项目会话。项目组可折叠并支持键盘，搜索选中折叠项目后会展开；路径写法差异不拆组。关闭视图不删除历史、草稿或后台生成，重启后也不自动生成替代会话。上述行为有定向自动化，但尚无真实桌面验收。
- 显式移除项目授权已接入主进程、预加载和侧栏二次确认。撤销立即隐藏授权、取消项目任务、清除会话绑定并关闭该项目终端；历史不删除。同一真实路径重新授权复用原项目 ID，旧会话可恢复。授权设置写入失败会报错并回滚内存，不能伪称撤销成功。全量回归曾通过 160 个测试文件、1215 项；持久化失败保护的追加定向测试通过。仍待真实桌面和失效项目复核。
