## 本轮自动化实测

运行 `npm run smoke:browser-mcp`，通过官方 stdio MCP 真实连接已开启远程调试的
Chrome，且仅操作临时本机页面。以下链路已通过：

- 官方工具发现（共至少 24 个工具）与 `list_pages`；
- `new_page`、`take_snapshot` 及官方 UID；
- `fill`、`click`、`evaluate_script`；
- `take_screenshot`；
- `list_console_messages`、`list_network_requests`；
- `navigate_page` 刷新；
- 先用 `select_page` 切换内部选中页，再用 `close_page` 关闭测试页；
- 客户端、官方 MCP 子进程与临时 HTTP 服务正常退出。
- 设置页可按需测试官方连接并显式断开；启动应用本身不会提前启动 MCP 或触发授权提示。

真实验证发现并修复：关闭当前选中页前必须先选择其他页；最后一页按 Google 官方
工具约束不允许关闭。未在本轮自动化覆盖的人工验收项继续保持未勾选。
