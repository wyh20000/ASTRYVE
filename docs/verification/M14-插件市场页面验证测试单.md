## 页面人工复核步骤

1. 设置 → 插件 → 市场源，添加 HTTPS 索引并同步。
2. 在推荐、官方、社区和分类间切换，使用名称、说明、作者、来源或能力搜索目标插件。
3. 打开全屏详情页，核对作者、来源、验证状态、组件、能力、数据目标、兼容性、权限、更新记录和 SHA-256 后确认安装；返回后列表搜索、分组和滚动位置保持。
4. 在“已安装”显式启用插件，新建任务并触发插件工具。
5. 准备新增权限或更换签名密钥的新版本，确认详情页要求重新确认；更新后检查备份并执行回滚，再卸载。
6. 分别在常规窗口和最小支持宽度复核列表、详情页、键盘操作和错误提示。
7. 安装并启用一个声明 `network` 权限与 HTTPS MCP 的插件；分别完成无需登录、API Key 和 OAuth 系统浏览器授权，确认页面进入“已连接”。
8. 对已连接服务执行重新授权；制造一次连接失败后执行重试，并确认失败连接仍可主动断开。
9. 将同一兼容连接绑定到两个插件，确认页面提示共享影响；主动断开后确认两处均回到“待连接”，新任务不再获得对应工具。
10. 导入并启用声明 `ui/index.html` 的插件，打开插件详情中的“打开插件界面”；核对独立窗口显示、关闭方法、禁用/更新/回滚/卸载时自动关闭，以及网络、外链、下载和权限请求被拒绝。

以上页面步骤本轮未人工执行，实际结果留待验收人填写。
