## 已执行结果

1. `npm run smoke:browser` 通过启动、打开 URL、等待页面稳定、审查、CSS 定位、点击、截图和停止。
2. 新增 `browser.waitForPage`，等待目标来源且 `document.readyState=complete`，支持截止时间与取消。
3. 修复新 CDP 会话未先 `DOM.getDocument` 时搜索 nodeId 无法解析的问题。
4. Agent 的读取、导航和写入工具均向 Gateway 传递 callId、来源、风险、截止时间和取消信号。
5. Chrome 子进程环境移除 Electron/Node 注入变量；专用资料和临时 smoke 数据已清理。
6. 全量基线：89 个测试文件、490 项测试通过；Node/Web 类型检查和生产构建通过；高危依赖审计为 0；`git diff --check` 无空白错误。
7. DOM 自动识别密码、验证码、卡号和令牌字段；真实 Chrome smoke 已验证普通内容也不能写入密码框。
8. DOM 自动识别提交、发送、删除、购买和支付控件；普通点击被 Gateway 拒绝，只有高风险 `browser.confirmClick` 可执行。
9. 高风险确认点击和浏览历史仅提供单次审批；Windows 关闭 Chrome 使用 PID 进程树回收。
10. 页面文本和语义轮廓返回显式截断标志，避免模型把局部内容当成完整页面。

## 页面人工复核步骤

1. 设置 → 浏览器，启动独立 Chrome，确认资料目录不是日常 Chrome 默认目录。
2. 在对话中要求打开测试页，依次执行等待、审查、定位、输入/点击、页面与元素截图。
3. 对新网站、普通输入和高风险动作核对审批弹窗与工具时间线。
4. 取消执行中的读取与交互，再重启 Chrome，确认不重放写操作。
5. 在常规窗口和最小支持宽度复核状态、允许/阻止列表和错误提示。
