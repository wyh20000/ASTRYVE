## 2. 准备测试插件

准备一个只做无害读取或纯文本处理的受信任测试插件。`plugin.json` 至少包含：稳定 ID、名称、三段式版本、说明、权限，以及一个带封闭参数结构的工具。工具入口必须是插件目录内的相对路径。

- [ ] 文件夹版插件可以正常导入。
- [ ] 同一插件打成 ZIP 后可以正常导入。
- [ ] 插件列表显示真实名称、版本、说明和权限，不显示本机安装路径。
- [ ] 导入完成后列表自动刷新，无需重启应用。

## 3. 安装与清单安全

- [ ] 导入缺少清单或 JSON 损坏的插件时，页面给出简短错误，其他插件仍可使用。
- [ ] 清单使用绝对路径、`../`、URL 入口或开放对象参数时，导入被拒绝。
- [ ] 含符号链接、目录联接、原生可执行文件或异常压缩内容的包被拒绝。
- [ ] 用同一 ID 更新失败时，旧版本仍保留可用，页面没有半安装项目。
- [ ] 禁用插件后，新对话任务不再获得该插件工具。

## 4. `@插件` 选择

- [ ] 在输入框键入 `@` 后，只出现已启用且含工具的插件。
- [ ] `↑`、`↓` 可移动选中项，Enter 或 Tab 可确认，Esc 可关闭。
- [ ] 点击菜单外部可以关闭菜单，鼠标也能选择候选。
- [ ] 选中后，输入框上方出现可移除标签；点击关闭只移除该插件提及。
- [ ] 发送后，模型看到的正文不包含已解析的 `@插件ID`，但其他 `@文字` 和附件不受影响。
- [ ] 手工输入不存在、已禁用或无效的插件 ID 时，收到简短且可理解的错误。

## 5. 任务快照与实时变化

- [ ] 启动一个会调用插件的长任务，然后在设置中禁用或更新该插件。
- [ ] 当前任务提示“插件已变化”，但不会静默替换正在使用的工具版本。
- [ ] 停止当前任务后再次发送，新任务使用最新启用状态和版本。
- [ ] 导入、启停、恢复和自动隔离后，设置页状态实时刷新。

## 6. DeepSeek 与 Kimi 真实调用

分别配置真实可用的 API Key，确认输入框和回复插件提示显示实际模型名称。

- [ ] DeepSeek 能从结构化工具目录选择测试插件，而不是在普通文本里伪造调用。
- [ ] DeepSeek 多轮工具调用后仍能继续回复，思考字段、调用 ID 和消息顺序正常。
- [ ] Kimi 能完成同一插件的工具调用与 `role=tool` 结果回传。
- [ ] 不显式写 `@插件` 时，模型在任务需要时可以自主选择已启用插件。
- [ ] 模型尝试调用未声明工具、错误参数或未授权操作时被拒绝，插件入口不执行。

## 7. 权限、审批与取消

- [ ] 只读模式下，写入、命令和联网类插件工具被拒绝。
- [ ] 请求批准模式下，敏感插件工具先显示项目自定义审批弹窗。
- [ ] 审批摘要简短，长参数只在折叠详情中显示且弹窗内部滚动。
- [ ] 拒绝审批后工具不执行，模型收到受限错误结果。
- [ ] 调用过程中点击停止，Worker 收到取消，页面恢复可操作且没有残留忙碌状态。

## 8. 崩溃、超时和隔离恢复

- [ ] 让测试插件入口抛错，错误只影响该插件调用，主窗口和其他插件不崩溃。
- [ ] 让插件不返回或停止心跳，超时后任务可停止，界面不卡死。
- [ ] 让插件返回超过 200KB 的结果，调用被拒绝且不展示整段超长内容。
- [ ] 连续失败三次后，插件显示“已隔离”，且不再进入新任务工具目录。
- [ ] 点击“恢复”后状态回到可重试；新任务可再次调用，旧调用不会自动重放。

## 9. 审计与隐私

- [ ] 审计中可定位任务 ID、调用 ID、真实模型名、插件 ID、版本、来源、工具名和结果状态。
- [ ] 审计不包含 API Key、完整工具参数、完整返回结果、清单正文或本机绝对路径。
- [ ] 清除审计后历史敏感摘要不再显示，但已安装插件和会话不被删除。
