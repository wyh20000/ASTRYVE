# 02 · 第一阶段计划（P1：页面样式 + 会话系统）

> 本阶段只做两件事：**1) 完整还原设计稿页面样式；2) 流畅的对话与会话系统（本地 Mock，不接真实 AI）。**
> 技术选定：React + TypeScript + Electron（electron-vite）+ Tailwind CSS + headless 组件库 + mysql2（MySQL）+ Zustand。
>
> **状态（2026-08-30）**：P1 已完成，P2 也已完成代码与自动化验收；P2 详情见《04-第二阶段计划.md》和《05-二阶段未完成项.md》。本文保留为 P1 历史计划。

## 1. 阶段目标

1. **界面可交付**：按 `docs/design-ref.png` 完整呈现两栏（左栏 + 对话主区）+ 状态栏，视觉与交互接近设计稿。
2. **会话可用**：能新建/切换/搜索/重命名/删除会话，会话与消息本地持久化，重启不丢。
3. **对话流畅**：输入 → 发送 → 消息上屏（含思考态、计划、文件列表等结构化展示骨架）→ 滚动跟随；通过本地 Mock 模拟 AI 回复，验证整条数据流与 UI。
4. **架构立得住**：主/preload/渲染三端分层、typed IPC、shared 类型、DB store 就位，为 P2 接模型打底。

> 本阶段**不接任何真实 API、不做真实 FS/终端/浏览器能力**。

## 5. 会话系统设计

### 5.1 交互
- 新建：顶栏「＋/新对话」→ 生成新 Session 并进入；`Cmd/Ctrl+N`。
- 切换：点击列表项 → 激活并加载该会话消息。
- 重命名：会话项菜单 / 双击标题。
- 删除：会话项右键/悬停菜单 → 确认框。
- 搜索：顶栏搜索框（`Cmd/Ctrl+K`）按标题/内容过滤。
- 分组：今天 / 昨天 / 更早，按 `updatedAt` 计算。
- **默认新对话**：启动时若无空的新会话则新建并选中。

### 5.2 数据流（单向）
```
UI 触发 action
  → Zustand store 调用 window.agent.session.* (typed IPC)
  → Main: IPC handler 校验 → store 读写 MySQL（或内存兜底）
  → 返回 IpcResult<T>
  → store 更新内存态 → 组件 re-render
```

### 5.3 DB Schema（P1）
```sql
CREATE TABLE IF NOT EXISTS sessions (
  id VARCHAR(64) PRIMARY KEY,
  title VARCHAR(512) NOT NULL,
  project_path VARCHAR(512),
  pinned TINYINT(1) NOT NULL DEFAULT 0,
  created_at BIGINT NOT NULL,
  updated_at BIGINT NOT NULL,
  INDEX idx_sessions_updated (updated_at DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS messages (
  id VARCHAR(64) PRIMARY KEY,
  session_id VARCHAR(64) NOT NULL,
  role VARCHAR(16) NOT NULL,
  content MEDIUMTEXT NOT NULL,
  blocks MEDIUMTEXT,
  status VARCHAR(16) NOT NULL DEFAULT 'done',
  timestamp BIGINT NOT NULL,
  INDEX idx_messages_session_time (session_id, timestamp),
  CONSTRAINT fk_messages_session FOREIGN KEY (session_id) REFERENCES sessions(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 5.4 自动标题
- 首条用户消息取首行 ≤30 字作默认标题，可在 UI 重命名。

## 6. 对话交互设计

- **消息结构**：消息含 `blocks` 字段支持结构化块：`text`（markdown）、`thinking`（思考态）、`plan`、`files`、`code`。
- **思考块**：思考中全展示；结束后自动收起为「思考过程」胶囊，可点击展开。
- **代码块**：显示语言标签 + 复制按钮 + 语法高亮。
- **Mock 流程**：本地按时间轴依次 `streaming`：思考徽标 → 计划列表 → 文件列表 → 文本回复 → `done`。
- **滚动**：新消息自动滚到最底；用户上滑暂停自动滚动，提供「滚动到底」浮标。
- **输入**：`Enter` 发送、`Shift+Enter` 换行；发送后清空并聚焦；空内容不可发送。

## 7. 技术要点与落地选型

| 事项 | 做法 |
| --- | --- |
| Electron 脚手架 | `electron-vite`（react-ts） |
| IPC 类型安全 | `shared/ipc.ts` 常量 + `shared/types.ts` + preload `index.d.ts` |
| DB | `mysql2`（MySQL）优先，连不上回退 `MemoryStore`；`DbStore` 抽象隔离后端 |
| 状态 | Zustand（session/chat/ui/theme/model 各一 store） |
| 样式 | Tailwind + CSS 变量令牌；dark/light 由 `color-scheme` + `dark` class 控制 |
| markdown | `react-markdown` + `remark-gfm` + `rehype-highlight`；代码块用自定义 `RichText` 切分 + `highlight.js` |
| 主题 | `theme.ts` 预设 + `buildTheme`（背景/文字/强调色派生） |

## 10. 验收标准（Definition of Done）

1. 主界面（左栏 + 对话主区 + 状态栏）在 1440×900 下还原度达 90% 以上（对照 design-ref）。
1b. 设置页可切换多套预设主题并自定义背景色/文字颜色/强调色，即时全局生效，重启后保持；颜色输入不跳动。
2. 会话 CRUD + 搜索 + 分组 + 自动标题全部可用；数据持久化、重启不丢、删除正确级联。
3. 发送/接收消息流程流畅，滚动跟随正确，markdown 与代码块（语言+复制）正常。
4. Mock 流程能完整演示「思考 → 计划 → 文件 → 文本」，无卡顿。
5. 主/preload/渲染分层清晰，`window.agent` 类型安全，IPC 统一返回 `IpcResult`。
6. TypeScript strict / lint 通过；关键 repos 与纯函数有单测（Vitest）。
7. 不引入任何真实 AI/FS/终端/浏览器能力（评审时验证）。

## 11. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| MySQL 连接不上 / 无服务 | 无法持久化 | 已做 `MemoryStore` 降级；配置 `MYSQL_*` 环境变量 |
| MySQL 凭据/库不存在 | 连接失败 | 自动 `CREATE DATABASE IF NOT EXISTS`；凭据走环境变量 |
| 深色 UI 还原细节多、耗时 | 工时膨胀 | 先骨架后细节；走查清单化 |
| 会话/消息量增大卡顿 | 滚动/渲染差 | 消息列表虚拟化；分页/懒加载 |
| 范围蔓延（想顺手做 AI） | 进度失控 | 严格遵守 §2.2 范围外清单 |
