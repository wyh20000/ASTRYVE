## 1. 整体结构

- **三栏布局**：左栏会话侧栏（约 220px）＋ 中栏对话主区（自适应）＋ 右栏代码工作区（约 480px）。
- 顶部为窗口标题栏区（含「新对话」tab、会话标题、智能模式徽标）。
- 底部一条全局状态栏。
- 整体为**近黑深蓝**底，低饱和、冷色调；分隔线极细；强调色为**蓝色**。

```
┌────────────┬──────────────────────────────────┬──────────────────────┐
│  Sidebar   │  Chat 主区                        │  Workspace           │
│  ~220px    │  顶栏：新对话 | 实现登录功能 | 智能模式 │  代码/终端/任务/日志 │
│ 可折叠     │  会话消息流                        │  文件树 + 代码编辑区  │
│            │  输入框                           │  终端 + 调试控制台    │
│            │                                   │  状态栏(文件/行列等)  │
└────────────┴──────────────────────────────────┴──────────────────────┘
```

## 5. 主题与细节（还原要点）

| 项 | 要点 |
| --- | --- |
| 背景层级 | 应用底 > 面板 > 浮层，逐层略亮；用 `--bg-app/panel/raised/active` |
| 分隔线 | 1px，极低对比（`--border`），避免生硬 |
| 强调色 | 蓝色（`--accent`），用于：选中会话边框/背景、激活 tab、链接、智能模式徽标、发送按钮 |
| 文本 | 主文本近白、次要灰蓝、弱文本更暗（占位/时间） |
| 圆角 | 中栏卡片/按钮圆角；侧栏列表行圆角小 |
| 代码 | 高亮配色贴近 VS Code 深色；行号弱化；终端日志用分色（INFO 等） |
| 间距 | 面板内边距约 12–16px；列表行高约 32px；块之间留呼吸感 |

> **校准建议**：开发时用取色器对 design-ref 采样，把实际色值回填到 `tokens.ts`，保证“所见即所得”。还原顺序：先整体布局与令牌 → 再逐栏组件 → 最后交互/动效。

## 6. 一致性与可访问性（P1 基线）

- 同一语义组件全局统一（按钮、列表项、徽标、tab），避免重复实现。
- 关键对比度：正文文本对背景 ≥ 4.5:1；弱文本用于非关键信息。
- hover/active/disabled 三态齐全；focus 可见（outline）。
- 图标用统一 SVG 集（如 lucide-react）保持一致线宽与大小。
