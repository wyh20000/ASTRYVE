# Workspace file icons

These SVG assets are a small, vendored subset of [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme), version 5.38.1.

Material Icon Theme is distributed under the MIT license. The license is included in `MATERIAL-ICON-THEME-LICENSE`. The assets are bundled locally so the desktop app does not need a network request to render workspace files.
